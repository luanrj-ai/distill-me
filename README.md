# 蒸蒸你 · distill-me

把你自己蒸馏成一份"数字分身档案"。全程在**你自己的电脑**上进行,原始聊天记录**不会外传**,只导出一份你逐条过目、删改后的 JSON 档案。

## 安装(一条命令)

前提:装了 [Claude Code](https://claude.com/claude-code)。然后:

```bash
git clone https://github.com/luanrj-ai/distill-me.git ~/.claude/skills/distill-me
```

## 使用(分两天,共约 80 分钟)

**第一天(~50 分钟)**
1. 打开终端,进任意目录,运行 `claude`
2. 输入:**蒸馏我**(或 `/distill-me`)
3. 先快速答 25 道小题,然后跟着聊 30-40 分钟(任何问题都可以说"跳过";想停随时停)
4. 结束后它会问"确认上传吗?"——你点头它就替你交回;不点头/没网,档案在桌面,手动发回也行

**第二天(~30 分钟)**
1. 再运行 `claude`,输入:**蒸馏我 第二天**
2. 把那 25 道小题再答一遍(别翻昨天的),然后和"你的分身"聊几轮,顺手说哪像哪不像
3. 同样确认后上传

## 你的隐私

- 它会(经你同意后)读你本机的 Claude 历史对话当素材——**只在本机读,原始记录绝不上传**
- 上传的只有:经你逐块过目、删改、并明确确认后的那份档案
- 档案里不含你的真实姓名;桌面永远留一份你自己的底
